## 📌 Sobre o Repositório

Este repositório reúne aplicações e experimentos desenvolvidos para resolver problemas reais utilizando **Inteligência Artificial GenAI, LLMs, Agentes Autônomos e Análise de Dados**. 

O objetivo principal é demonstrar a integração prática entre back-end estruturado em Python, bancos de dados relacionais e interfaces modernas de consumo de IA.
